📌 Project Overview

Recipe Blog is a web-based application developed to provide users with a collection of delicious recipes. Users can explore different dishes, view ingredients, and follow step-by-step cooking instructions.

✨ Project Features
Browse different food recipes
View recipe ingredients
Read step-by-step cooking instructions
Explore various dishes
User-friendly web interface

⚙️ How to Run the Project
Install Java JDK and IntelliJ IDEA.
Install and configure MySQL.
Open the Recipe Blog project in IntelliJ IDEA.
Configure the database connection in application.properties.
Make sure the MySQL database is created.
Run the Spring Boot main application class.
Open your browser and visit:

http://localhost:8080/
